# Protocol Package Guidelines

`@gol/protocol` is the shared compatibility layer for the repository. It must remain independent of the agent, web, and subgraph packages.

## Sources of Truth

- `src/abi.ts` exposes contract ABIs used by TypeScript consumers.
- `src/constants.ts` owns shared chain and protocol constants.
- `src/amount.ts` owns exact amount parsing and validation.
- `src/types.ts` owns shared schemas and API/domain types; `src/index.ts` defines the public surface.
- `dist/` is generated by TypeScript and must not be edited.

Do not duplicate ABIs, addresses, validation schemas, or domain types in downstream packages. Export only stable consumer-facing APIs. Contract interface changes must be reconciled with Solidity and the subgraph before release. Represent token values as validated integer base units; do not introduce floating-point amount math.

## Testing

Add focused Vitest regression coverage for validation boundaries, amount conversion, and serialized API shapes.

- `pnpm --filter @gol/protocol typecheck`
- `pnpm --filter @gol/protocol test`
- `pnpm --filter @gol/protocol build`
